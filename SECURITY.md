# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/nhl4000/awsport/security/advisories/new)
rather than opening a public issue. Include the version (`awsport version`),
your OS, and steps to reproduce.

You can expect an acknowledgement within a few days. Fixes ship as a new patch
release; `awsport update` installs it.

## Supported versions

Only the latest release receives fixes.
